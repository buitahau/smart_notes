# Smart Notes Landing Page & Dashboard

A modern, responsive landing page and user dashboard for Smart Notes - an AI-powered note-taking and task management Chrome extension with unified chat interface.

## Features

### Landing Page
- 🎨 Modern, responsive design using Tailwind CSS
- ⚡ Built with Next.js 14 and React 18
- 🎯 Smooth animations with Framer Motion
- 📱 Mobile-first responsive design
- 🚀 Performance optimized
- ♿ Accessibility focused

### User Dashboard
- 📊 Interactive charts showing note statistics
- 📈 Daily, monthly, and yearly note creation trends
- 🥧 Category distribution pie chart
- 📋 Real-time statistics cards
- 🎯 Recent activity tracking
- 📱 Fully responsive design

### Admin Dashboard
- 🔐 Secure admin authentication system
- 📊 Platform-wide analytics and statistics
- 👥 User management with search and filtering
- 💰 Revenue tracking and reporting
- 📈 User growth and engagement metrics
- 🎛️ Admin-only navigation and features

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) to view the landing page.
4. Visit [http://localhost:3000/dashboard](http://localhost:3000/dashboard) to view the user dashboard.
5. Visit [http://localhost:3000/admin/login](http://localhost:3000/admin/login) to access the admin dashboard.
